
# MarkdownLive

A real-time Markdown blogging platform built using
Next.js, TypeScript and Tailwind CSS.

## Project Overview

MarkdownLive allows users to write blog posts using
Markdown and view formatted HTML previews instantly.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase (planned)
- React Markdown (planned)

```bash

```
